# Reprise de code de Lunii.QT

## Accord

- **Projet source** : Lunii.QT, d'o-daneel (https://github.com/o-daneel/Lunii.QT), et le fork
  de scarlaty (https://github.com/scarlaty/Lunii.QT), publiés sous GPL v3.
- **Accord** : o-daneel autorise la reprise de code de Lunii.QT dans flam-launcher sous
  licence **MIT**. Accord déclaré par le mainteneur du dépôt le 17/10/2026 ; aucune trace écrite
  de l'échange n'est versionnée.
- **Périmètre** : tout Lunii.QT (code amont d'o-daneel) et les ajouts du fork scarlaty, mode
  « carrier » compris. scarlaty est l'auteur des ajouts du fork et les place sous la même licence.

## Obligations dans ce dépôt

- Chaque fichier qui reprend ou adapte du code de Lunii.QT porte en tête :

  ```text
  Partie de ce fichier est adaptée de Lunii.QT (https://github.com/o-daneel/Lunii.QT),
  Copyright (c) o-daneel, reprise sous licence MIT avec l'accord de l'auteur
  (voir docs/licences/lunii-qt.md).
  ```

- La reprise est signalée dans la description de la PR concernée (fichiers et fonctions
  d'origine).
- Le code repris n'apporte aucune clé, aucun secret d'appareil ni contenu officiel Lunii : les
  clés restent lues sur l'appareil ou fournies par l'utilisateur.
