# Flam Launcher 0.1.0-beta.1

**Première pré-version destinée aux testeurs.** Elle n'est pas une version stable : des défauts sont
attendus, et c'est précisément ce que cette bêta doit faire remonter.

Flam Launcher est une application Windows pour gérer des histoires sur une Flam (la conteuse
d'histoires) sans passer par des outils en ligne de commande.

## Ce que fait cette version

- **Bibliothèque** : liste, tri et suppression des histoires installées.
- **Sources** : ajout de sources d'histoires (dossier ou catalogue en ligne) et mises à jour.
- **Conversion Telmi vers Flam** : le convertisseur est embarqué (aucun Python ni outil externe à
  installer) ; ffmpeg est livré dans l'installateur.
- **Transfert direct vers la Flam**, par USB :
  - firmware **1.x** : validé, en mode « carrier » ;
  - firmware **2.x** : **expérimental, à tester**. C'est le cœur de cette bêta : vos retours sur
    ce point sont les plus utiles.

## Avant de commencer

1. **Sauvegardez votre Flam** : copiez tout son contenu sur votre ordinateur avant le premier
   transfert. Le launcher ne fait pas de sauvegarde complète automatique (il ne conserve que
   l'index et les fichiers `.mdf`).
2. **L'installateur n'est pas signé.** Windows SmartScreen affichera un avertissement : cliquez
   sur « Informations complémentaires », puis « Exécuter quand même ». L'installation se fait
   pour l'utilisateur courant, sans droits d'administrateur.
3. **Vérifiez l'empreinte SHA-256** du fichier téléchargé avec `SHA256SUMS.txt`, joint à cette
   release. Dans PowerShell, depuis le dossier de téléchargement :

   ```powershell
   Get-FileHash .\Flam-Launcher_0.1.0-beta.1_x64-setup.exe -Algorithm SHA256
   ```

   La valeur affichée doit être identique à celle de `SHA256SUMS.txt`.

## Limites connues

- Pré-version : l'interface et les formats peuvent encore changer.
- Transfert vers une Flam en firmware 2.x : expérimental (voir ci-dessus).
- Installateur non signé (SmartScreen).
