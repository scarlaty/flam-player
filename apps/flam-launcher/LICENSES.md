# Licences des composants redistribués

Ce fichier est installé à la racine de Flam Launcher. Il liste les composants livrés par
l'installateur et renvoie vers leurs textes de licence complets, présents dans l'installation
(`licenses/` et `telmi2flam/LICENSES.md`). En cas de divergence, le texte de licence fait foi.

| Composant                                                                              | Licence                                                                                                                                          | Texte dans l'installation                                                 |
| -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------- |
| Flam Launcher (`flam-launcher.exe`)                                                    | MIT                                                                                                                                              | `licenses/flam-launcher-LICENSE.txt`                                      |
| flam-player (`flam-player.exe`)                                                        | usage personnel et éducatif (dépôt flam-player) ; redistribué avec l'accord du mainteneur                                                        | `README.md` du dépôt, section « Licence »                                 |
| SDL2 (`SDL2.dll`)                                                                      | zlib                                                                                                                                             | `licenses/SDL2-LICENSE.txt`                                               |
| Lua 5.4 (lié dans `flam-player.exe`)                                                   | MIT                                                                                                                                              | `licenses/Lua-LICENSE.txt`                                                |
| LVGL 8.3 (lié dans `flam-player.exe`)                                                  | MIT                                                                                                                                              | `licenses/LVGL-LICENCE.txt`                                               |
| minimp3 (lié dans `flam-player.exe`)                                                   | CC0 1.0 (domaine public)                                                                                                                         | `licenses/minimp3-LICENSE.txt`                                            |
| Police Nunito (glyphes convertis en bitmap, `flam-player.exe`)                         | SIL Open Font License 1.1                                                                                                                        | https://openfontlicense.org                                               |
| Police Montserrat 14 (intégrée à LVGL, `flam-player.exe`)                              | SIL Open Font License 1.1                                                                                                                        | https://openfontlicense.org                                               |
| Convertisseur `telmi2flam/` : scripts et moteur Lua                                    | usage personnel et éducatif (dépôt flam-player) ; redistribué avec l'accord du mainteneur                                                        | `telmi2flam/LICENSES.md`                                                  |
| Runtime Lunii `telmi2flam/runtime/` (bibliothèque Lua, icônes)                         | propriété de leurs auteurs (Lunii) ; le mainteneur du dépôt confirme avoir les droits de redistribution (issue #21, « Décisions du mainteneur ») | `telmi2flam/LICENSES.md`                                                  |
| Python embarqué (`telmi2flam/python/`, dont libffi, libtommath, `python.cat`)          | PSF-2.0 et licences des composants                                                                                                               | `telmi2flam/python/LICENSE.txt`                                           |

Les dépendances de l'application elle-même (bibliothèques Rust compilées dans
`flam-launcher.exe`, paquets npm compilés dans l'interface) sont sous licences permissives
(MIT, Apache-2.0, ISC, BSD, MPL-2.0 pour certaines) ; leur liste exhaustive se génère depuis
`Cargo.lock` et `package-lock.json` (non embarquée dans l'installateur).
